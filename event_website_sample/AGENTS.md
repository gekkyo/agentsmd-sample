# 学内イベントサイト（架空の Next.js プロジェクト）

## 概要

大学の広報室が、学生・教職員向けに講演会や展示会の情報を公開するサイト。Next.js の App Router を使う。申込は各イベントの外部フォームに案内し、サイト内では個人情報を受け取らない。

## ディレクトリ構成

ファイルの配置に迷った場合は、`README.md` の「ディレクトリ構成」を確認する。

## 開発・検証コマンド

- パッケージマネージャーは npm。初回セットアップは `npm ci`。
- 画面を確認しながら作業するときは `npm run dev`。
- コード変更後は `npm run lint`。イベントのデータ・一覧・詳細・日時表示を変更したら、関連テストを更新して `npm test`。
- 完了前に `npm run build`。開発サーバーを動かしている場合は、停止してから実行する。

## イベントデータ

- イベント情報は `src/data/events.ts` が唯一の元データ。一覧と詳細はそこを参照し、ページに情報を重複して書かない。
- 各イベントには ID・タイトル・開始日時・終了日時・会場を持たせる。日時・会場・申込先は広報室の原稿に合わせ、未指定の値を推測で埋めない。原稿がない場合は確認する。
- 開始・終了日時はタイムゾーン付きの ISO 8601 形式で記録し、画面には日本時間で表示する。
- 公開済みイベントの ID は詳細ページの URL に使うため変更しない。変更が必要なら先にリダイレクト方針を確認する。

## 表示・公開ルール

- 一覧ではこれから開催するイベントを日時の早い順に並べる。開催済みイベントは一覧の末尾に残し、詳細ページにも直接アクセスできるようにする。
- 申込先が未定のイベントに仮の URL や申込ボタンを表示しない。ポスター画像だけに日時・会場・申込先を載せず、テキストでも表示する。
- 申込フォームや個人情報の保存機能は追加しない。必要になった場合は実装前に運用方針を確認する。

## 変更時の確認

- 一覧・詳細を変更したら、公開済みイベントの URL と開催済みイベントの表示を確認する。
- 日時を扱う変更では、日付をまたぐイベントと終了日時が開始日時より後になることをテストする。
