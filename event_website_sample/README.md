# 学内イベントサイト（架空の Next.js プロジェクト）

大学の広報室が、学生・教職員向けに講演会や展示会を案内するサイトです。イベントの一覧と詳細を公開し、申込は各イベントの外部フォームへ案内します。このサイト自体に申込フォームや管理画面はありません。

## はじめに

Node.js と npm を用意し、プロジェクトのルートで実行します。

```sh
npm ci
npm run dev
```

起動後、通常は `http://localhost:3000/events` でイベント一覧を確認できます。ポートが使われている場合は、ターミナルに表示された URL を確認してください。

## ディレクトリ構成

主要な場所だけを示します。

```text
src/
├── app/events/
│   ├── page.tsx           # イベント一覧（/events）
│   └── [id]/page.tsx      # イベント詳細（/events/[id]）
├── components/            # 画面で共通して使う部品
└── data/events.ts         # イベント情報の元データ
public/events/            # ポスター画像
```

一覧と詳細はどちらも `src/data/events.ts` のデータを使います。開催前のイベントは日時の早い順に表示し、終了後も詳細ページは残します。データベースは使っていません。

## イベント情報の更新

1. 広報室の原稿でタイトル、開始・終了日時、会場、申込先を確認します。不明な項目は推測で埋めず、原稿の担当者に確認します。
2. `src/data/events.ts` にイベントを追加・更新します。ID は詳細ページの URL に使うため、公開後は原則変更しません。
3. 日時はタイムゾーン付きの ISO 8601 形式（例：`2026-11-01T09:00:00+09:00`）で記録します。画面には日本時間で表示されます。
4. 必要なポスター画像を `public/events/` に置きます。日時や会場などは画像だけでなく、ページ上のテキストにも記載します。
5. 一覧と詳細を画面で確認します。申込先が未定なら申込ボタンは表示されません。

公開済みイベントの ID を変える必要がある場合は、旧 URL からのリダイレクトを含めて検討してください。

## 確認コマンド

```sh
npm run lint
npm test
npm run build
```

イベント情報や表示を変更したら、関連テストも更新します。`npm run build` は開発サーバーを停止してから実行してください。
